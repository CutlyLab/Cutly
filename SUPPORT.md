# Support

## Questions and integration help

Search the [documentation](README.md#documentation), existing issues and known
limitations first. If the answer is not present, open a GitHub issue with the
Cutly version or commit, operating system, Go/Node versions and the smallest
reproduction that does not contain private media.

## Bug reports

Use the bug-report form and include expected behavior, actual behavior and the
exact verification command. For render problems, include FFmpeg/FFprobe version
and build identities, selected Cutly profile and sanitized logs. Do not upload
private projects, media, credentials, absolute user paths or signing material.

Release candidates intentionally reject unsupported semantics. Check
[KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md) before reporting a missing feature
as a defect.

## Security

Do not file a public issue for vulnerabilities or trust-boundary bypasses.
Follow [SECURITY.md](SECURITY.md).
